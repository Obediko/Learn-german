# Resource Library

This course is resource-selective. The curriculum controls the sequence; resources supply practice.

## 1. FunoGerman — primary adaptive practice engine
Repository source-of-truth: `Obediko/funogerman-langua-internal/docs/master-curriculum.md`.
Use FunoGerman for personalized conversation, selective correction, immediate retry, retrieval and weak-area recycling.

## 2. Goethe-Institut — official CEFR/exam calibration
A1 adult practice materials:
https://www.goethe.de/en/spr/prf/ueb/pa1.html

Use for Weeks 6, 12–13 and final exam-style practice. The official page provides listening, reading, writing and speaking practice material.

For A2, use the corresponding Goethe A2 exam-training section from the Goethe exam practice hub:
https://www.goethe.de/en/spr/prf/ueb.html

Do not use Goethe tests as daily teaching material. Use them as checkpoints and pressure tests.

## 3. vhs-Lernportal — structured high-volume practice
A1 course:
https://a1.vhs-lernportal.de/

A2 course:
https://a2.vhs-lernportal.de/

The A2 course has 12 lessons and roughly 900 exercises. Use VHS for extra grammar/listening/reading drills when the weekly diagnostic identifies a weakness. Do not mindlessly complete every exercise.

## 4. Easy German / Super Easy German — authentic listening
Main site:
https://www.easygerman.org/

Use Super Easy German heavily in A1 and early A2. Move gradually toward normal Easy German street interviews in late A2.

Protocol:
1. first listen without English subtitles;
2. second listen for details;
3. use German subtitles/transcript;
4. extract at most five phrases;
5. shadow 30–60 seconds;
6. retell the video aloud.

## 5. Kurs DaF / Klett — sequencing benchmark
FunoGerman's master curriculum already maps A1.1/A1.2/A2.1/A2.2 to Kurs DaF lessons. Use legally available owned materials/audio as supporting practice where available. Do not copy proprietary exercises into this repository.

## 6. Dictionary and pronunciation support
Use Duden or DWDS for German definitions/usage where useful and a reputable pronunciation source for uncertain words. Dictionary use should confirm meaning after context, not replace reading/listening inference.

## Resource rule by phase
Weeks 1–6: Funo + Super Easy German + selective VHS A1.
Weeks 7–13: Funo + VHS A1 + Goethe A1 checkpoints + Super Easy German.
Weeks 14–19: Funo + VHS A2 + Easy German A2 material.
Weeks 20–25: Funo + VHS A2 + authentic Easy German + Goethe A2-style tasks.
Week 26: Goethe-style assessment + Funo conversation stress test.

## Anti-resource-hopping rule
For a single concept, use one primary explanation and at most one backup explanation. If you spend more than 15 minutes searching for 'the perfect German video', stop searching and practise the current task.
