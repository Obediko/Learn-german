# Writing and Grammar Track

## Grammar mastery principle
Grammar counts only when you can use it while communicating. Every new structure goes through four stages:
1. notice it in context;
2. produce controlled sentences;
3. transform sentences;
4. use it spontaneously in speech and writing.

## Grammar map
Weeks 1–2: sein, haben, present tense, W-questions, yes/no questions, basic word order.
Weeks 3–4: accusative foundations, möchten, negation, separable verbs, time-first inversion.
Weeks 5–6: possessives, modal verbs, consolidation.
Weeks 7–8: es gibt, dative/location chunks, first Perfekt with haben/sein, war/hatte.
Weeks 9–10: müssen/sollen/können, imperative chunks, comparisons and shopping structures.
Weeks 11–13: weil and verb-final subordinate clauses; A1 repair.
Weeks 14–15: productive Perfekt, Präteritum of sein/haben/modals, sequencing, comparisons.
Weeks 16–17: polite Konjunktiv-II chunks, formal requests, future with werden, dass.
Weeks 18–19: wenn, recommendation language, A2.1 consolidation.
Weeks 20–22: clarification structures, formal email grammar, practical case/preposition consolidation.
Weeks 23–24: deshalb/trotzdem, connected narration, subordinate-clause fluency.
Weeks 25–26: cumulative A2 accuracy and B1 bridge diagnostics.

## Writing ladder
Weeks 1–2: 40–60 words: profile, hobby note.
Weeks 3–6: 60–80 words: shopping, routine, family message.
Weeks 7–13: 80–100 words: housing inquiry, sick message, invitation/reply, past event.
Weeks 14–19: 100–130 words: biography, housing comparison, complaint, plans, recommendation.
Weeks 20–24: 120–150 words: university inquiry, application email, banking inquiry, travel account.
Weeks 25–26: 150–180 words under time pressure.

## Writing workflow
1. Identify purpose and recipient.
2. List 5 target words and 2 target structures.
3. Write without translator.
4. Check only: verb position, tense, case/article, spelling/capitalization, connectors.
5. Correct no more than 5 highest-value errors.
6. Rewrite the corrected sentences once.

## Grammar production test
For each target structure, produce:
- 5 affirmative statements;
- 3 questions;
- 3 negative statements;
- 3 personalized examples;
- 2 spontaneous examples during speaking.
A structure is not mastered if it only works in fill-in-the-blank exercises.

## Error log codes
WO = word order
V = verb form/tense
CASE = article/case
PREP = preposition
LEX = vocabulary/collocation
SPELL = spelling/capitalization
PRON = pronunciation
FLU = fluency/hesitation

Track recurring errors. If the same code appears 3 times in a week, it becomes next week's repair target.
