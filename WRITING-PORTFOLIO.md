# German Writing Portfolio — September to March

Writing is cumulative evidence of growth, not a set of disposable exercises. Save one polished artifact from each major stage.

26. Week 26 — timed 150–180 word final task

## Draft cycle
1. Write without translator.
2. Check task completion.
3. Check verb position, tense, case, spelling, connectors.
4. Correct at most five highest-value errors.
5. Rewrite the complete text once.
6. Revisit 48 hours later and reproduce key structures without looking.

## Error codes
- WO — word order
- V — verb/tense
- CASE — case/article
- PREP — preposition
- LEX — vocabulary/chunk
- SPELL — spelling
- PRON — pronoun/reference
- COH — cohesion

Three repeats of the same error code within one week automatically create next week's repair target.

## Hub requirement
Store every portfolio artifact with date, week, first draft, corrected version, main error codes and self-rating. The learner should be able to compare Week 1 with Week 26 side-by-side.
